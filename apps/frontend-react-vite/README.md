# Hometab Frontend

React 19 single-page application built with Vite and embedded in the Hometab Go binary.

## Commands

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

The development server runs on `http://localhost:5173` and proxies `/api` requests to `http://127.0.0.1:52173`.

## Stack

- React 19 and Vite
- Tailwind CSS and Radix UI
- TanStack Query
- dnd-kit
- React Hook Form and Valibot
- i18next

See [the development guide](../../docs/DEVELOPMENT.md) for the complete local workflow.
