# Changelog

Hometab follows Semantic Versioning. Release tags use `vX.Y.Z`.

## [Unreleased]

- Add macOS login startup controls to the embedded settings UI.
- Share LaunchAgent lifecycle logic between the local API and CLI.

## [1.0.0]

Initial public release.

- Single-binary Go and React application with local SQLite persistence.
- Grouped links, reusable flows, drag-and-drop ordering, and multi-engine search.
- Saved HTTP actions with structured input and constrained network execution.
- Bing and custom wallpapers with local fallback and cache management.
- Automatic and manually managed domain icons.
- Versioned ZIP backup, merge import, replace restore, and automatic restore points.
- Simplified Chinese and English interfaces.
- macOS user service installation and multi-platform release builds.
